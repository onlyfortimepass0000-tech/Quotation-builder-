# Quotation Builder

Upload a company's sample quotation PDF → AI turns it into a template → you approve it → generate new quotes as PDFs (no AI calls at generation time).

Next.js 16 · Neon Postgres · Vercel Blob · NVIDIA NIM.

```bash
npm install
npm run dev
```

Setup, env vars and deploy steps: see [HANDOFF.md](HANDOFF.md).
